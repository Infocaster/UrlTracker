The URL Tracker built by Infocaster B.V. makes URL management effortless. Your visitors will never get lost when your website structure changes. Whether a page is moved, renamed, or deleted, the URL Tracker automatically keeps track of those changes and redirects visitors to the correct destination.
Not only does this create a seamless experience for your users, it also helps preserve your SEO rankings in Google and other search engines by preventing broken links and lost traffic.
The URL Tracker gives you full control over redirects. Create simple redirects from one URL to an Umbraco page, or build advanced redirect rules using Regular Expressions for more sophisticated scenarios.
It is an essential tool for content editors and developers migrating to a new Umbraco website, helping ensure users and search engines always find the right content.
Supported Umbraco Versions
The URL Tracker is actively developed for the latest versions of Umbraco, including:

- **Umbraco 13** — featuring a completely redesigned backoffice UI
- **Umbraco 17** — with the frontend fully rewritten using Lit for improved performance and maintainability
